# gpu-mon-control - archived version

This version is an archived Windows mouse sensitivity tool.

It provides basic cursor movement correction for stretched or non-native display proportions. The reference resolution is built into the program, so changing it requires editing the source and rebuilding the application.

This archived version does not include user profiles, GPU or display-output switching, System Tray controls, configurable hotkeys, background controls, command-based controls, or automatic configuration reload.

For normal use, download the current release package instead of this archived version.
